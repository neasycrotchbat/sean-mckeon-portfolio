Druk / Druk Text web fonts (Commercial Type)
============================================

The site's CSS expects these licensed WOFF2 files here:

  Druk-Medium-Web.woff2        -> 'Druk' 400        (name, nav headings, project titles)
  DrukText-Regular-Web.woff2   -> 'Druk Text' 400   (body copy)
  DrukText-Medium-Web.woff2    -> 'Druk Text' 500   (emphasis)

Buy web licences at https://commercialtype.com, drop the files in this
folder with these exact names (or update the @font-face blocks at the
top of css/styles.css), commit and push. Until the files exist the site
renders with the Google-font stand-ins Anton and Oswald, matching the
design prototype's fallback behaviour.
